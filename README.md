# Interactive Quiz Maker

A clean, zero-dependency interactive web quiz application with a classical Dark Mode design. Create and take interactive mock exams effortlessly straight from your browser. 

## Features
- **Zero Installations Required:** Runs natively in any modern web browser. You do not need to install Node.js, Python, or VS Code to use this app.
- **Dynamic Scramble Engine:** Intelligently shuffles the overall question order AND completely randomizes the multiple-choice options (A, B, C, D) on every single run to prevent pattern guessing.
- **Dual Data Handling:** Supports seamlessly uploading a `.json` file, or simply copy-pasting your raw clinical questions into the text box.
- **Classical Aesthetic:** Features an elegant, eye-friendly Classic Dark Mode and interactive feedback elements.

## How to Run the App

1. **Clone the project** to your computer by opening your terminal and running:
   ```bash
   git clone https://github.com/AneeshNagdev/Quiz-maker.git
   ```

2. **Open the Folder** and simply **double-click the `run_quiz.bat` file**. 
   This will automatically spring everything to life and launch the application directly in your default web browser for you.

3. **Provide your data** by either uploading a file or pasting raw text in the prompt box, and enjoy your exam prep!
